1. The Container Widget 1. الحاوية (Container)

What, Why, and How?ماذا، لماذا، وكيف؟

What: A convenience widget that combines common painting, positioning, and sizing elements. It's like a `div` in HTML. ماذا: عنصر واجهة يجمع بين التلوين، التموضع، وتحديد الحجم. يشبه وسم `div` في HTML.

Why: Use it when you need to add padding, margins, borders, background colors, or specific dimensions to a single child widget. لماذا: استخدمه عندما تحتاج لإضافة هوامش (Margin/Padding)، حواف، ألوان خلفية، أو أبعاد محددة لعنصر واحد.

How: Wrap your widget in a Container. Provide width, height, padding, or decoration. كيف: ضع العنصر داخل Container. حدد العرض width، الطول height، أو الزخرفة decoration.

Container( width: 200.0, height: 100.0, padding: const EdgeInsets.all(16.0), margin: const EdgeInsets.only(top: 10.0), decoration: BoxDecoration( color: Colors.blue, borderRadius: BorderRadius.circular(8.0), ), child: Text( 'Hello Flutter!', style: TextStyle(color: Colors.white), ), )

2. Row (Horizontal Layout) 2. الصف (Row) - التخطيط الأفقي

What, Why, and How?ماذا، لماذا، وكيف؟

What: A widget that displays its children in a horizontal array (side-by-side). ماذا: عنصر يعرض أبناءه في ترتيب أفقي (جنباً إلى جنب).

Why: To build horizontal layouts like navbars, icon/text pairs, or horizontal lists. لماذا: لبناء تخطيطات أفقية مثل أشرطة التنقل، أو أيقونة بجوار نص.

How: Use Row(children: [...]). Control spacing using mainAxisAlignment (horizontal) and crossAxisAlignment (vertical). كيف: استخدم Row(children: [...]). تحكم في المسافات باستخدام mainAxisAlignment (أفقياً) و crossAxisAlignment (رأسياً).

Row( // Align items horizontally (Main Axis) mainAxisAlignment: MainAxisAlignment.spaceBetween, // Align items vertically (Cross Axis) crossAxisAlignment: CrossAxisAlignment.center, children: [ Icon(Icons.home), Text('Home Page'), Icon(Icons.arrow_forward), ], )

3. Column (Vertical Layout) 3. العمود (Column) - التخطيط الرأسي

What, Why, and How?ماذا، لماذا، وكيف؟

What: A widget that displays its children in a vertical array (top-to-bottom). ماذا: عنصر يعرض أبناءه في ترتيب رأسي (من الأعلى للأسفل).

Why: Almost every mobile app screen flows vertically! Use it to stack UI sections. لماذا: تقريباً كل شاشات التطبيقات تتدفق رأسياً! استخدمه لترتيب أقسام الواجهة فوق بعضها.

How: Use Column(children: [...]). Now, mainAxisAlignment is vertical, and crossAxisAlignment is horizontal! كيف: استخدم Column(children: [...]). هنا، mainAxisAlignment أصبح رأسياً، و crossAxisAlignment أصبح أفقياً!

Column( // Align items vertically (Main Axis) mainAxisAlignment: MainAxisAlignment.start, // Align items horizontally (Cross Axis) crossAxisAlignment: CrossAxisAlignment.stretch, children: [ Image.network('url.jpg'), SizedBox(height: 20), // Spacing Text('Article Title'), Text('Article Body...'), ], )

4. Stack (Z-Axis Overlapping) 4. المكدس (Stack) - التراكب

What, Why, and How?ماذا، لماذا، وكيف؟

What: A widget that positions its children relative to the edges of its box. Children overlap each other. ماذا: عنصر يضع أبناءه بناءً على حواف الصندوق الخاص به. الأبناء يتراكبون فوق بعضهم (Z-Axis).

Why: Perfect for notification badges, profile pictures with edit icons, or text overlaid on an image. لماذا: مثالي لشعارات الإشعارات، صور الملف الشخصي مع أيقونة التعديل، أو كتابة نص فوق صورة.

How: Use Stack(children: [...]). The first child is at the bottom. Use the Positioned widget to place children exactly where you want them. كيف: استخدم Stack(children: [...]). الابن الأول يكون في الأسفل. استخدم Positioned لوضع الأبناء في أماكن دقيقة.

Stack( alignment: Alignment.center, children: [ // Bottom layer Container( width: 100, height: 100, color: Colors.blue, ), // Top layer overlapping Positioned( top: 0, right: 0, child: Icon(Icons.check_circle, color: Colors.green), ), ], )

Spot the UI Bug 1: Container Errors اكتشف خطأ الواجهة 1: أخطاء الـ Container

This Flutter code causes a red "Assertion Failed" error screen. Why?

هذا الكود يسبب شاشة خطأ حمراء (Assertion Failed) في فلاتر. لماذا؟

1. A Container must always have a child. 1. الحاوية (Container) يجب أن تحتوي دائماً على child.
2. You cannot provide both a color outside and a decoration with a color. 2. لا يمكنك توفير color بالخارج واستخدام decoration في نفس الوقت.
3. BoxDecoration requires a borderRadius. 3. الـ BoxDecoration يتطلب تحديد borderRadius.
Container( width: 200, height: 200, // ❌ ERROR CAUSING CODE color: Colors.red, decoration: BoxDecoration( color: Colors.blue, borderRadius: BorderRadius.circular(10), ), child: Text('Hi'), )

Spot the UI Bug 2: Row Overflow اكتشف خطأ الواجهة 2: تجاوز حدود الـ Row

When running this code, you see yellow and black stripes warning you about a "RenderFlex Overflow" on the right side. How to fix it?

عند تشغيل الكود، تظهر خطوط صفراء وسوداء تحذرك من "RenderFlex Overflow" على اليمين. كيف تصلح ذلك؟

1. Give the Row a fixed width. 1. إعطاء الـ Row عرضاً ثابتاً (width).
2. Wrap the wide Container (or the Text) inside an Expanded or Flexible widget. 2. تغليف الـ Container العريض بـ Expanded أو Flexible.
3. Change mainAxisAlignment to center. 3. تغيير mainAxisAlignment إلى center.
Row( children: [ Icon(Icons.info), // ❌ Too wide for a normal mobile screen! Container( width: 800, color: Colors.grey, child: Text('A very long text description...'), ), ], )

Spot the UI Bug 3: Stack Placement اكتشف خطأ الواجهة 3: أماكن الـ Stack

Column( children: [ Text('Profile Image:'), // ❌ ERROR: Misplaced Widget Positioned( top: 10, right: 10, child: Icon(Icons.edit), ), Image.asset('avatar.png'), ], )

This layout throws an error regarding incorrect widget usage. Why?

هذا التخطيط يعطي خطأ بسبب الاستخدام غير الصحيح للعنصر. لماذا؟

1. Positioned must be a direct child of a Stack, not a Column. 1. Positioned يجب أن يكون ابناً مباشراً لـ Stack، وليس Column.
2. The Image.asset is missing dimensions. 2. الصورة Image.asset تفتقر إلى الأبعاد (Dimensions).
3. Column needs crossAxisAlignment: CrossAxisAlignment.stretch. 3. Column يحتاج إلى crossAxisAlignment: stretch.

Spot the UI Bug 4: Expanded Usage اكتشف خطأ الواجهة 4: استخدام Expanded

Container( color: Colors.grey, padding: const EdgeInsets.all(20), // ❌ ERROR: Incorrect ancestor for Expanded child: Expanded( child: Text('I want to fill space!'), ), )

This code throws a Flutter error about parent constraints. Why?

هذا الكود يعطي خطأ في فلاتر يخص قيود الأب (Constraints). لماذا؟

1. Expanded needs a flex factor to work. 1. Expanded يحتاج إلى قيمة flex ليعمل.
2. Container cannot have both color and padding. 2. Container لا يمكن أن يحتوي على لون وحواف داخلية معاً.
3. Expanded must be a descendant of a Row, Column, or Flex. 3. Expanded يجب أن يكون بداخل Row أو Column أو Flex.

The Golden Rules of Flutter Layouts القواعد الذهبية لتصميم واجهات فلاتر

  • Container: Use it for margins, padding, styling, and sizing a single widget. Container: استخدمه للهوامش، الزخرفة، وتحديد حجم عنصر واحد.
  • Row/Column: Use for linear direction. Remember Main and Cross axes swap! Row/Column: استخدمهما للترتيب الخطي. تذكر أن المحاور الرئيسية والفرعية تتبدل!
  • Expanded: Essential inside Row/Column to prevent Overflow errors and fill space. Expanded: ضروري داخل الـ Row/Column لمنع أخطاء تجاوز الحدود (Overflow).
  • Stack: Use when widgets need to overlap on the Z-Axis. Pair with Positioned. Stack: استخدمه عندما تحتاج لتراكب العناصر فوق بعضها. ادمجه مع Positioned.
